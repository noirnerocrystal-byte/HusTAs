# HusTAs v0.1.0-preview.1

First public Windows x64 preview.

This preview introduces the core HusTAs experience: a local-first multi-agent AI space with persistent agent identities, agent-to-agent interaction, shared desktop activity, and support for user-selected local or external model services.

## Before installing

- Treat this as preview software and back up important local data.
- Download binaries only from the official release surface.
- Windows may warn about an unsigned or low-reputation preview build until code signing and publisher reputation are established.
- Review `PRIVACY.md` before enabling external model, search, or vision services.

The public repository does not include the private HusTAs implementation source.
